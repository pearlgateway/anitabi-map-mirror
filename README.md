# Anitabi 动画巡礼地图镜像

这是一个 [anitabi.cn](https://www.anitabi.cn) 动画巡礼地图的静态镜像站点。

## 数据说明

- 数据来源：[anitabi.cn](https://www.anitabi.cn) 开放 API
- 收录作品：760 部动画
- 地标数量：5,988 个（lite 数据，每部作品前 10 个地标）
- 最后更新：2026-07-01

## 功能

- 在地图上显示所有动画取景地标
- 按作品筛选地标
- 搜索作品名称
- 点击地标查看截图和详细信息

## 技术栈

- Leaflet.js + OpenStreetMap 底图
- 纯静态 HTML/CSS/JS

## 部署

本仓库通过 GitHub Pages 自动部署。
